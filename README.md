## Быстрый старт (Docker)
1. Запуск Docker Desktop
2. В корне проекта выполните в PowerShell or Terminal
docker compose up --build
```
3. Автоматически сгенерируется файл с ключом
```
4. Ключ в файле `generated_api_key.txt`. Скопируем ключ.

- UI доступен по адресу: `http://localhost:8080/`
- MySQL доступен на порту `33060` (локально) - если не работает, то очистите процессы, работающие на этом порту, как правило это сам MySQL, запущенный ранее

Остановка в другом окне терминала:
docker compose down
```

## Аутентификация
X-API-Key: введите его в поле для входа
```
